# TP3 — Terrains sportifs

Structure de départ pour le projet d’équipe. Aucune donnée de terrain n’est fournie.

## Lancer localement

Dans VS Code, lancez Live Server depuis `index.html` pour ouvrir l’application dans le navigateur via un serveur local.

## Fichiers

- `index.html` : page principale
- `css/style.css` : styles adaptatifs
- `js/app.js` : chargement de la liste et sélection d’un terrain
- `js/details.js` : affichage des détails (US3)
- `data/terrains.json` : tableau vide à remplir avec les données convenues par l’équipe
